## 🧭 Cómo trabajo como Tech Lead

</div>

Lidero el software que mueve la tienda: cobro en piso, almacén y canal digital. El código de producto es privado; esto es el rol y el alcance.

<table align="center">
<tr>
<td valign="top" width="33%">

**Punto de venta**

- POS en Android para terminales SUNMI. Cobra con o sin internet, calcula precios en el aparato, parte el cobro y no pierde la venta si se cae la red.
- UI de Compose compartida entre apps de piso.
- Precios del ticket alineados con el ERP, al centavo.

</td>
<td valign="top" width="33%">

**Almacén y liderazgo**

- Inventario por código de barras y RFID.
- Surtido en piso y verificación de mercancía.
- Dashboard para parámetros a pistolas y terminales.
- Releases, code review y estándares del equipo.

</td>
<td valign="top" width="34%">

**API, canales y cloud**

- API en .NET: pedidos y tickets.
- Traductores de delivery y marketplaces (Foodbot, Mercado Libre, Uber).
- Facturación web por folio de ticket.
- eCommerce: Shopify, Tiendanube.
- Cloud: GCP, Vercel, Fly.io.

</td>
</tr>
</table>

En el día a día saco releases, reviso PRs y dejo el POS, el almacén y las colas hablando el mismo idioma.

## 📊 Dónde está el trabajo de verdad

</div>

Las tarjetas automáticas de GitHub **solo ven repositorios públicos**. En esta cuenta eso es casi solo este README y `ai-specs`. El día a día está en repos privados: PRs, releases y review.

```yaml

    - dashboard_dispositivos
```
