## 🧭 Cómo trabajo como Tech Lead · Agentic Developer

</div>

Soy **Tech Lead** y **Agentic Developer**: coordino un equipo multidisciplinario de desarrollo para múltiples productos — aplicaciones **Android**, **iOS** y **web**, más **cloud** — y meto agentes y copilotos al flujo de trabajo del equipo. El código de producto es privado; esto es el rol y el alcance.

<table align="center">
<tr>
<td valign="top" width="33%">

**Android**

- Apps Kotlin / Compose en piso y almacén.
- Cobro en terminales SUNMI, con o sin red.
- Inventario (barras y RFID), surtido y verificación.
- UI de Compose compartida entre apps.

</td>
<td valign="top" width="33%">

**iOS y web**

- Apps iOS en Swift para el mismo ecosistema.
- Aplicaciones web: facturación, dashboards y backoffice.
- Conectores de eCommerce (Shopify, Tiendanube) y canales (Foodbot, Mercado Libre, Uber).

</td>
<td valign="top" width="34%">

**Cloud**

- **GCP**, **Vercel** y **Fly.io**.
- APIs .NET: pedidos y tickets.
- Linear para priorizar el trabajo del equipo.
- Agentes, MCP y reglas para copilotos (`ai-specs`).
- Coordino rumbo técnico, releases y review.

</td>
</tr>
</table>

En el día a día coordino al equipo, saco releases y dejo Android, iOS, web y cloud hablando el mismo idioma.
