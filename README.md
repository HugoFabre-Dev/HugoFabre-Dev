## 🏬 En Proscai

</div>

Trabajo en el software que mueve la tienda: cobro en piso, almacén y lo que entra desde el canal digital. La organización es [proscai](https://github.com/proscai). El código del producto es privado; esto es lo que construyo.

<table align="center">
<tr>
<td valign="top" width="33%">

**Punto de venta**

- **ePOS / Rompefilas** — POS en Android para terminales SUNMI. Cobra con o sin internet, calcula precios en el aparato, parte el cobro y no pierde la venta si se cae la red.
- **proscai-ui** — componentes de Compose que comparte el POS.
- Precios del ticket alineados con el ERP, al centavo.

</td>
<td valign="top" width="33%">

**Almacén**

- **Colector** — inventario por código de barras y RFID.
- **Picker** — surtido en piso.
- **Checker / Verificador** — validar mercancía.
- **Dashboard SUNMI** — parámetros a las pistolas y terminales sin entrar al portal del fabricante.

</td>
<td valign="top" width="34%">

**ERP y canales**

- **Proscai API** en .NET: el núcleo que materializa pedidos y tickets.
- Traductores que bajan órdenes de delivery y marketplaces a pedido de Proscai (Foodbot, Mercado Libre, Uber).
- **Facturación web** por folio de ticket.
- Conectores de eCommerce: Shopify, Tiendanube.

</td>
</tr>
</table>

En el día a día saco releases, reviso PRs y dejo el POS, el almacén y las colas hablando el mismo idioma.

## 📊 Dónde está el trabajo de verdad

</div>

Las tarjetas de stats, la racha y el calendario verde de más abajo **solo ven repositorios públicos**. En esta cuenta eso es casi solo este README y `ai-specs`. Por eso el perfil se ve vacío aunque el día a día no lo sea.

El código del producto vive en la org [proscai](https://github.com/proscai), en repos privados. Ahí es donde abro PRs, saco versiones y reviso al equipo.

```yaml
# esto no lo pintan las APIs públicas de GitHub
trabajo_en_proscai:
  pos:
    - ePOS / Rompefilas   # SUNMI, cobro offline
  almacen:
    - Colector            # inventario, barras y RFID
    - Picker              # surtido en piso
    - Checker             # verificador de mercancía
    - dashboard_sunmi     # parámetros a pistolas y terminales
  backend_y_canales:
    - Proscai API         # .NET: pedidos y tickets
    - traductores         # Foodbot, Mercado Libre, Uber
    - facturacion_web     # folio de ticket
    - ecommerce           # Shopify, Tiendanube

en_esos_repos:
  - pull requests
  - releases del POS
  - code review
```

Los cuadrados verdes del perfil **pueden** reflejar eso si en GitHub activo “Include private contributions” y la org lo permite. Estas tarjetas del README, no: son un servicio público, sin token, y no voy a poner uno aquí.
